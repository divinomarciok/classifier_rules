📊 RESUMO DO QUE VOCÊ VAI FAZER
══════════════════════════════════════════════════════════════════════════

Sua API terá:

1. Endpoints de Categorias
   - GET /api/categorias (listar)
   - GET /api/categorias/{id} (obter)
   - POST /api/categorias (criar)
   - PUT /api/categorias/{id} (atualizar)
   - DELETE /api/categorias/{id} (deletar)

2. Endpoints de Regras
   - GET /api/regras (listar)
   - GET /api/regras/{id} (obter)
   - GET /api/regras/categoria/{id} (por categoria)
   - POST /api/regras (criar)
   - PUT /api/regras/{id} (atualizar)
   - DELETE /api/regras/{id} (deletar)

3. Endpoints de Classificação
   - POST /api/classify (classificar um)
   - POST /api/classify/batch (classificar lote)

4. Endpoints de Auditoria (read-only)
   - GET /api/auditoria (listar)
   - GET /api/auditoria/{id} (obter)
   - GET /api/auditoria/produto/{id} (por produto)
   - GET /api/auditoria/regra/{id} (por regra)
